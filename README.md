# MVP UniPassport — Единый цифровой паспорт абитуриента

Инновационный прототип международной платформы-агрегатора университетов с функцией единого цифрового паспорта для абитуриентов. Проект разработан с учетом требований к высоким нагрузкам (Highload) и имеет готовую базу для масштабирования на миллионы пользователей.

## 🚀 Архитектурные особенности для Highload
1. **Распределенные идентификаторы (UUIDv4)**: Все первичные ключи сущностей (вузы, студенты, заявки, специальности) спроектированы в формате UUID. Это исключает коллизии при слиянии баз данных, позволяет генерировать ключи на стороне клиентов и готовит систему к шардированию.
2. **Индексация поиска и связей**: В базе данных (SQLite с совместимым синтаксисом под PostgreSQL) настроены составные и одиночные B-Tree индексы на внешние ключи отношений и поля статусов, что гарантирует высокую скорость выполнения SQL-запросов.
3. **Готовность к кэшированию**: Бизнес-логика бэкенда разделена на чистые REST API-эндпоинты. Архитектура готова к быстрому внедрению Redis-кэширования для тяжелых запросов чтения (например, список одобренных университетов и специальностей).
4. **Асинхронный Telegram-модератор**: Взаимодействие с Telegram Bot API происходит асинхронно, не блокируя основной поток запросов клиентов.

## 🛠️ Стек технологий
- **Бэкенд**: Python 3.10+, FastAPI (асинхронный фреймворк), SQLAlchemy 2.0 (ORM с поддержкой UUID).
- **Фронтенд**: SPA (Single Page Application) на чистом HTML5, CSS3 (переменные, Flexbox, Grid, Glassmorphism) и Vanilla JS (роутер, Chart.js, AJAX-клиент).
- **Интеграция**: Telegram Bot API (инлайн-кнопки обратного вызова).

## ⚙️ Быстрый запуск

### 1. Подготовка окружения
Перейдите в директорию проекта `uni-passport`:
```bash
cd uni-passport
```

Создайте и активируйте виртуальное окружение Python:
```bash
# Windows (PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

Установите необходимые пакеты:
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (`.env`)
Файл `.env` в корне проекта уже настроен под предоставленные вами данные:
- Токен вашего бота: `8786733634:AAHw_MMpggoiMBkxNtFt7iD9yin1bzfqFJM`
- Ваш Chat ID: `203525674`
- Локальная база данных SQLite: `uni_passport.db`

*Для работы бота в локальном режиме включена опция фонового опроса (Long Polling), поэтому вам не нужен ngrok или публичный IP-адрес.*

### 3. Запуск веб-сервера
Запустите FastAPI-приложение через uvicorn:
```bash
uvicorn backend.main:app --reload --port 8000
```

После запуска:
- **Интерфейс платформы**: откройте в браузере [http://localhost:8000](http://localhost:8000).
- **Интерактивная документация API (Swagger UI)**: [http://localhost:8000/docs](http://localhost:8000/docs).
- При первом запуске база данных автоматически создастся и наполнится демонстрационным вузом **Aetheris Global University** с его специальностями.

## 🧭 Как протестировать функционал MVP?

### 1. Регистрация нового ВУЗа и модерация в Telegram
1. Перейдите в футер сайта и кликните на ссылку **"Для университетов"**.
2. Заполните короткую форму (название вуза, имя контакта, контакты) и нажмите **"Отправить на верификацию"**.
3. Статус вуза запишется в БД как `pending` (на модерации).
4. На ваш телефон в Telegram-бот мгновенно придет сообщение с данными вуза и двумя инлайн-кнопками: `[🟢 Одобрить]` и `[🔴 Отклонить]`.
5. Нажмите кнопку **`🟢 Одобрить`** прямо с телефона. Сообщение в боте изменится на *"Модерация завершена! Статус: Одобрен"*, а в базе данных статус вуза обновится на `approved`.
6. Обновите главную страницу сайта — новый вуз появится в списке доступных!

### 2. Подача документов и Цифровой паспорт абитуриента
1. На главной странице кликните по карточке вуза **Aetheris Global University** для просмотра деталей или сразу нажмите кнопку **"Подать заявку"**.
2. Вы будете перенаправлены в раздел **"Цифровой паспорт"**. Для демонстрации анкета уже предзаполнена данными из ваших скетчей (Староверов Даниил Дмитриевич, IELTS: 7.5, SAT: 1420 и т.д.).
3. Выберите специальность (например, *"Компьютерные науки и ИИ"*), выберите тестовый файл (аттестат/сертификат в PDF или картинку) и нажмите **"Подать заявку"**.
4. В этот момент:
   - Создастся (или обновится) ваш Единый Цифровой Паспорт в БД.
   - Заявка привяжется к выбранному вузу со статусом `pending`.
   - На экране появится зеленая плашка: **«Документы успешно переданы в приемную комиссию»**.
   - Левая колонка («Цифровой паспорт») и список поданных заявок обновятся без перезагрузки страницы.

### 3. Панель управления директора университета (Админка)
1. Перейдите в раздел меню **"Панель управления"**.
2. Здесь отображается дашборд директора вуза Aetheris Global University:
   - Карточки ключевых показателей (Просмотры, Количество лидов, Конверсия).
   - Интерактивный премиум-график динамики заявок и трафика за последние 7 дней (на базе Chart.js).
   - **Таблица лидов**: содержит реальные данные абитуриентов, подавших документы через свой профиль.
3. Вы можете кликнуть по ссылке **`Скачать`** в строке абитуриента, чтобы загрузить прикрепленный им файл.
4. Вы можете изменить статус заявки в выпадающем списке (например, на *"На рассмотрении"* или *"Одобрен ВУЗом"*). База данных обновится мгновенно!
